🔐 Random Password Generator

A modern and responsive Random Password Generator built using HTML, CSS, and JavaScript.

✨ Features

* Generate secure random passwords instantly
* Adjustable password length using a slider
* One-click password copy functionality
* Clean and modern UI
* Responsive design
* Smooth animations and visual effects

 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)

 🚀 How to Use

1. Adjust the password length using the slider.
2. Click **"Hit me to generate password"**.
3. Copy the generated password using the copy icon.
